# Бот Lumio: заявки из Mini App и ответы клиентам

Одна функция Yandex Cloud делает всё:
- принимает заявки из Mini App (с фото) и присылает их администратору в @LumioMultBot;
- отвечает клиентам на вопросы через YandexGPT по файлу `knowledge.md`;
- если не уверен — пересылает вопрос администратору; ответ администратора (реплаем) уходит клиенту.

## Что поменять без программиста
- **Ответы бота** — правьте `knowledge.md` и загрузите функцию заново (новая версия).
- **Цены** — в `knowledge.md` и в `index.html` Mini App (блок `CONFIG`).

## Переменные окружения функции
| Имя | Что это |
| --- | --- |
| `BOT_TOKEN` | токен @LumioMultBot из @BotFather |
| `WEBHOOK_SECRET` | любая длинная случайная строка (латиница и цифры) |
| `PUBLIC_URL` | ссылка на функцию, `https://functions.yandexcloud.net/…` |
| `ADMIN_CHAT_ID` | ваш chat id (бот покажет его по команде `/myid`) |
| `FOLDER_ID` | ID каталога Yandex Cloud |

## Служебные ссылки
- Подключить вебхук: `PUBLIC_URL?src=setup&key=WEBHOOK_SECRET` — открыть один раз в браузере.
- Mini App шлёт заявки на `PUBLIC_URL?src=order`.

## Реклама в Telegram Ads: 600 ссылок и кабинет менеджера
- Ссылки: `https://t.me/LumioMultBot?start=ad001` … `ad600` (список сам дополняется до AD_LINKS_TOTAL=600; ещё — кнопкой «+ 10 ссылок» в кабинете).
- Бот пишет каждый переход с меткой и закрепляет человека за первой рекламной ссылкой; подписки, Mini App, вопросы, заявки и оплаты считаются в её пользу.
- Кабинет: команда `/cabinet` в боте присылает ссылку для менеджера. `/cabinet_new` — выдать новую (старая перестаёт работать). `/links` — все ссылки таблицей.
- Код: `bot/ads.py` (данные), `bot/cabinet.html` (страница), маршруты `/cabinet…` в `runner.py`.

## Бот ВКонтакте (vk.com/lumio.studio)

Файл `vk_bot.py`, запускается вместе с Telegram-ботом, если задан ключ сообщества:

```
read -s K; lumio-set VK_TOKEN "$K"
```

В сообществе: Управление → Работа с API → Long Poll API — включить, версия 5.199, события «Входящее сообщение» и «Исходящее сообщение»; Сообщения → Настройки для бота → «Возможности ботов» включить, «Кнопка Начать» включить.

Кнопки: бесплатный эскиз (подписчикам сообщества), заказ мультфильма (повод → длительность → герои → история → фото), примеры, цены, менеджер. Заявки попадают в общую CRM (источник «ВК: …»), уведомления — админу в Telegram со ссылкой на диалог ВК. Если админ ответил клиенту руками в ВК, бот ему молчит HUMAN_HOURS часов.

Метки: `vk.me/lumio.studio?ref=sketch|order|prices|examples|ad001`. Примеры-видео: `lumio-set VK_EXAMPLES "video-242968024_ID1,video-242968024_ID2"`.
